PROJECT: A macropad for symbols i use constantly but I often have to copy past them or search for their code to type it in the numerical keyboard.
 (Em Dash)
(Caret)
(Square Root)
(Ohm)
(Plus-Minus)
(Pi)
(Approximately Equal)

To use it should be pretty simple, just solder the components and plug it to the computer (in theory) should work.

I made this project to start learning hardware design
